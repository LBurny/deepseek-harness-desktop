# 中文说明

[← 返回 v0.5.22 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.22) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.22)

本版四项修复、一项组件更新：插件装包对 pnpm store 漂移自愈（`ERR_PNPM_UNEXPECTED_STORE`）、远程连接不再被 Cloudflare 的空闲斩杀"隔两分钟断一下"、远程隧道不再连败后永久放弃、dsh 插件页头部手机端排版修复；内嵌 cloudflared 升至 2026.9.3。运行时与会话格式不变，覆盖安装即可。

### 1. 插件装包：启动时自动检测并修复 store 漂移

在 dsh 插件页安装/更新插件时报 `ERR_PNPM_UNEXPECTED_STORE`（Unexpected store location），重启应用也无效。

插件的依赖树（profile 的 `node_modules`）链接在**创建它时**的 pnpm store（`node_modules/.modules.yaml` 里记录了当时的 store 路径），而每次实际执行安装的 pnpm 按你机器上的**全局配置**解析 store。两者一旦漂移——最常见的就是把 pnpm 全局 store 迁到另一个盘，或 pnpm 升级改变了默认 store 位置——对旧依赖树的任何安装/更新操作都会被 pnpm 直接拒绝，且没有自助出口：重启、重开插件页都没用，只能手工删掉整个依赖树重装。实锤场景：9 月 21 日把全局 store 迁到 F 盘后，9 月初建立的 profile 首次装插件即报错。

壳现在每次启动 dsh 前做一次检测：读依赖树记录的 store 路径，与内置 pnpm 实际解析到的 store 比对；不一致时自动修复——把旧依赖树改名备用 → 按清单和 lockfile 从新 store 重新链接（缺的包会从 npm 源下载）→ 成功后清掉备用。重链失败或超时（5 分钟预算）则回滚改名，旧依赖树原样保留——dsh 照常可跑，只是装包维持原报错，不会更糟。全程只在诊断日志（events.log）留痕，不弹任何提示；从没自定义过 store 的机器零开销通过。升级后首次启动日志里出现 `pnpm store heal: Healed { .. }` 即为修复完成，之后在 dsh 插件页重新安装即可。

### 2. 远程：页面放着不动不再"隔一阵断一下"

诊断日志里 dsh 的 SSE 事件流每 88~97 秒被 Cloudflare 边缘掐断一次（一周 278 条 "stream canceled by remote"）：Cloudflare 对静默长连接有约 100 秒的空闲斩杀窗口，quick tunnel 两端一静默 TCP 连接即被回收——手机端的主数据通道 WS remote.mux 同窗口受害，表现为放着不动两分钟就"断一下、自己重连"。

对策是壳代理里的**静默触发式保活**，通道活跃时一个保活帧都不发：WS 桥接下行静默满 30 秒，代理向浏览器发一帧空 Ping（浏览器协议层自动回 Pong，顺带把隧道反方向也焐热）；任意 SSE 响应上游静默满 30 秒，注入一行 `: keepalive` 注释帧（SSE 规范内合法注释，EventSource 客户端不可见）。dsh 本身零改动。若日志里再现 "stream canceled" 即为排查信号。

### 3. 隧道：连败后不再永久放弃

旧模型下隧道连续 5 次启动失败（指数退避 500ms→30s，全程约两分钟）即置 Failed 终态躺平——cloudflared 首次下载慢一点或网络抖得久一点，远程访问就死透，只能手动重开。现在 5 次快速失败后 Failed 状态照常对用户可见，但监督循环降级为每 5 分钟一次的无限慢速重试，任一次成功即复位回正常监督；停止语义不变（慢速等待期间 stop 依旧立即生效）。

### 4. 手机端：插件页头部排版修复

dsh 自带插件页的头部是单行 flex 且包内没有任何窄屏适配：390px 下"添加插件"按钮文字折成两行、intro 描述折行后 ⓘ 图标孤行。修复不藏任何控件、只调弹性：按钮文字永不折行、工具组不收缩、标题组允许收缩、intro 单行省略号截断（完整说明都在 ⓘ 的 tooltip 里，没有信息损失）。已按 390px 真实 dsh 0.2.0-rc.1 实例验证。

### 5. 兼容性

运行时与会话格式不变，会话、MCP 配置、技能、主题与语言选择全部原样保留。内嵌 cloudflared 升至 2026.9.3，下次隧道冷启动生效，不影响在跑隧道。插件面板维持 0.5.21 的退役状态（装插件走 dsh 自己的插件页）。Rust 全量测试通过（291 条，0 失败），含 store 自愈、保活注入与隧道降级重试的新回归。
