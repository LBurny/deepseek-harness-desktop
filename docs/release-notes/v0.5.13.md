This release fixes one rare but serious startup failure and tidies up two things on the phone UI. The bundled DeepSeek Harness runtime is unchanged, and no session data is affected - a normal in-place update is enough.

### 1. Fixed: the app could stop starting after an abrupt exit

While the harness works it holds a small lock file. If the app was killed at exactly the wrong moment - for example, quitting while it was still starting up - that lock file stayed on disk, and from then on every launch timed out waiting for it, so the app looked broken. The shell now clears abandoned lock files before every start, so the app recovers on its own. If an older install is already stuck: close the app fully, then delete the lock file (the source repo ships a small troubleshooting script, `scripts/check-dsh-locks.ps1`).

### 2. Fixed: duplicate icon in the model picker on phones

On narrow screens the model picker could show two icons side by side - a leftover custom icon next to the runtime's own icon. It now shows a single icon, as on the desktop.

### 3. Changed: turn stats moved into the Info tab on phones

The small line under the input box (rounds, steps, token usage) used to sit half cut off at the bottom edge of the screen. It now lives in the Info tab at the top, next to the other tabs, where it is easy to read.
