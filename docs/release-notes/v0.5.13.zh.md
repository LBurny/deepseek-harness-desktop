# 中文说明

[← 返回 v0.5.13 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.13) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.13)

本版修复一个「应用再也起不来」的启动故障，并顺手整理两处手机端界面。内嵌的 DeepSeek Harness 运行时不变，会话数据不受影响，按正常覆盖安装升级即可。

### 1. 修复：异常退出后应用可能再也起不来

harness 工作时会持有一个小锁文件；如果恰好在它持锁的瞬间被强杀（比如启动还没完成时就退出应用），锁文件会永久留在磁盘上，之后每次启动都卡在等锁超时——表现就是「应用坏了」。壳现在会在每次启动前清理这类遗留锁，应用自行恢复。旧版本被卡住的临时办法：彻底退出应用后删掉锁文件（源码仓附了排查脚本 `scripts/check-dsh-locks.ps1`）。

### 2. 修复：手机端模型选择处出现两个图标

窄屏上模型选择器会同时显示两枚图标（历史遗留的自造图标 + 运行时自带的图标）。现在只保留一枚，与桌面一致。

### 3. 调整：手机端回合统计移到顶部「信息」页

输入框下方那行「N 轮 N 步 / token 用量」原来贴着屏幕下缘、常被截断，现在整行搬进顶部「信息」标签页（与 对话/轨迹/项目 并列），点开即读。
