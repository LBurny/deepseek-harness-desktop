# 中文说明

[← 返回 v0.5.14 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.14) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.14)

本版修复「打开方式」等界面偏好每次重启都丢失的问题，并把手机端输入框底栏的间距排齐。内嵌的 DeepSeek Harness 运行时不变，会话数据不受影响，按正常覆盖安装升级即可。

### 1. 修复：「打开方式」等偏好每次重启都恢复默认

会话头部选了「用 VS Code 打开」，重启应用又变回文件资源管理器；会话宽度、当前会话、轨迹时长等几个界面偏好也同样记不住。根因：这些偏好存在浏览器存储里，按完整的本地地址（含端口）隔离，而此前每次启动都随机更换端口，等于每次都是全新站点、读不到上次写下的选择。现在应用会记住上次使用的端口并在下次启动时复用，偏好随源站稳定而保留。注意：本次升级后请重新选一次打开方式——旧选择留在已废弃的随机地址下，无法迁移。

### 2. 修复：手机端输入框底栏排版不等距

手机端输入框底部工具栏（左侧「+」与附件按钮，右侧模型选择、用量环与发送键）各件之间的间距参差不齐。现在全栏统一按钮尺寸与间距，并去掉两枚下拉小箭头，呈现更整齐的纯图标栏（手机端惯例）；各菜单的打开方式不变。
