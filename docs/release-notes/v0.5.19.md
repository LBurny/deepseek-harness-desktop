This release moves the embedded runtime from 0.1.6-alpha.1 to 0.2.0-rc.1, crossing six upstream releases at once: a plugin manager page, scheduled tasks and reminders, session archiving, keyboard shortcut editing, file change review and more. The shell keeps pace by retiring two runtime patches that upstream has now taken over natively (Explorer window visibility and stale lock recovery), plus two small mobile adaptation fixes. **The session format moves to V4 (one-way)** — everything else is unchanged: your data directory, configuration, skills and MCP servers survive install, uninstall and reinstall untouched. Update in place as usual.

### 1. Before you update: session format V4 cannot be downgraded

Upstream raised the session log format from V3 to V4 and ships the migration. On first launch after the upgrade, existing sessions are migrated automatically (the original files are kept), and every session created afterwards is V4 — **older releases cannot read V4 sessions**. In practice: if you roll back to 0.5.18 or earlier, sessions that existed before the upgrade still open (their V3 originals are on disk), but sessions created after the upgrade do not. The upgrade path is covered by the real-machine acceptance run, including the keep-your-data-directory first launch. The upgrade itself needs no action on your side.

### 2. Runtime highlights (spanning the 0.1.6, 0.1.7 and 0.2.0 lines)

- Plugin manager page: install, configure, enable/disable and uninstall at runtime; install from the official registry, a China mirror or a custom source, with the first install picking a reachable source automatically.
- Scheduled tasks and reminders: create and manage reminders, inspect run history, survive restarts, repeat as often as once a minute.
- Session archiving: pin, filter and restore; archiving a running session confirms the affected tasks first.
- Keyboard shortcuts: view, search, customize and restore, with the current bindings shown in the sidebar.
- File change review: per-turn change cards and side-by-side file diffs in the sidebar (split view, syntax highlight, synced scrolling).
- Sidebar previews extended to Word, Excel, PowerPoint, CSV and TSV; Excel gets sheet switching, cell selection and formulas.
- Auto review (experimental): can be enabled, and after rejecting an operation you decide whether to continue.
- A fresh install now creates a default workspace and an empty session on first launch, no folder picking required; there is also a first-use introduction (quota and usage choice, which may appear once after upgrading).
- Sessions on DeepSeek account models can search the web without an extra API key; account tasks and API-key tasks use separate model entries.
- The Windows built-in sandbox gained a permission diagnostics skill; conversations continue after tool scheduling errors instead of getting stuck.
- Also: voice input (experimental), MCP resource discovery and URI templates, SSH remote workspaces (experimental), browser-mode/subagent/plan panels in the sidebar, and tasks that keep running after you close the window (the app warns about them before quitting).

### 3. Shell changes

- **Explorer patch retired**: the "reveal in File Explorer opens nothing" fix from 0.5.17 is now native in 0.2.0 (the native command runner is parameterized, and explorer.exe is launched with an explicit visible window), so the shell patch is removed as planned. Behavior is unchanged: the window still opens with the file selected.
- **Stale lock recovery retired**: the "one hard kill can break the next launch" fix from 0.5.13 is now native — dsh 0.2.0 takes over locks whose holder process has died, so the shell no longer pre-scans before each launch.
- **Two mobile adaptation fixes**: the composer input became a contenteditable rich-text field, so the 16px font-size rule (the second line of defense against iOS focus zoom) now also targets contenteditable; the sidebar drawer width and shadow follow the new slot wrapper structure. A rule targeting a control that no longer exists was removed.
- The beta-notice seeding follows upstream's new settings namespace (ui-settings-general); leftover ui-onboarding entries in existing settings files are harmless.
- Mobile was re-verified at a real 390px viewport: the session header anti-squeeze from 0.5.18 still holds (76px tall, no overflow, constant 12px gaps, real ellipsis), stats row relocation, model trigger iconification and the full-screen settings dialog all pass; at 720px and above everything returns to the native form.

### 4. Compatibility

The V3 to V4 session format change (section 1) is the only compatibility break in this release. Your DSH data directory (sessions, MCP servers, skills, choices) survives install, uninstall and reinstall untouched; updating in place is enough, and on a phone one page reload picks the new adaptation up. The full Rust suite passes (290 tests, 0 failures), including the contract suite that probes the real runtime item by item.
