# 中文说明

[← 返回 v0.5.25 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.25) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.25)

本版修复预装 /init 命令在 dsh 会话格式 V4 下整轮失败的问题，并对 Rust 后端做零行为变化的内部重组。运行时与会话格式不变，覆盖安装即可。

### 1. 修复：/init 整轮失败 "format v4 message requires a producer-owned source kind"

dsh 0.2.0 的会话格式 V4 退役了通用 `kind: "plugin"` 消息源包装：持久消息必须声明生产者自有 kind，继续使用退役写法的整轮立即失败。0.1.2 世代预装的 /init 插件提交 AGENTS.md 编写提示词时仍走旧包装，导致每次调用当场报错。插件 0.1.4 起改发 `kind: "command-init"` + `form: "notice"`——与上游自家插件现行规范同款（plan-mode 写 `kind: "plan-mode"`、tool-goal 写 `kind: "tool-goal"`）；折叠的「上下文注入」行渲染不变（渲染只认 notice form）。历史会话无恙：V3→V4 迁移器自动改写旧包装（未登记名兜底 `plugin:<旧值>`）。

### 2. 内部重组

六个独立提交，每批 Rust 全量测试均绿。`dsh/` 收进程监督、凭证、上游事实、预设、端口与运行时模块（跟版时 upstream.rs 仍是唯一改动点）；`bootstrap/` 把启动期自愈收进单一入口 `run_all`（补丁 → pnpm store 自愈 → 插件播种），全部启动补丁收进 `bootstrap/patches/`——以后补丁随上游跟版增删只改这一个文件；`ui/` 收壳窗口设施，新增 `state.rs` 消除 theme↔tray 互引环；`features/` 收本地页面后端（commands.rs 并入 diagnostics.rs）。顶层新文件四个：logging.rs（events.log 统一追加层）、redact.rs（token 脱敏）、patchstore.rs（cordis.patch.yml 通用条目读写，自 mcp.rs 拆出）、eventbridge.rs（进程到窗口的事件桥）。lib.rs 从 1061 行瘦到 482 行，只剩组装。

### 3. 兼容性

除 /init 修复外用户可见面零变化：Rust 全量测试通过（293 条，3 条 ignored，0 失败），Tauri 命令名一个未动（命令注册三处锚定测试未改动即绿），安装钩子、权限清单、检查更新流程照旧；设置、会话、MCP 配置、技能、主题与语言选择全部原样保留。
