# 中文说明

[← 返回 v0.5.12 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.12) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.12)

本次更新把内置的 DeepSeek Harness 运行时升级到 0.1.5 系列，壳同步适配。升级本身大部分无感，但有三件事值得在更新前先看一眼。

### 1. 先看这条：会话格式升级是单向的

新运行时用新的会话格式存盘。打开旧会话时会自动转换并**保留原文件**，但转换后的会话没法和旧运行时兼容读取——如果之后回退到更早的应用版本，这些会话将打不开。这一点无法绕过，而且是 dsh 本身的行为，不是壳造成的。

### 2. 用极简模式的话看这条

极简模式（minimal）现在只给模型一个持久 shell。这个模式原先附带的文件读取与编辑工具不再提供，属上游设计调整；其它模式不受影响。

### 3. 手机端现在可以上传任意类型的文件

dsh 现在接受任意类型的文件，远程链接的传输方式也从"先收完再转发"改成边传边转。从手机上传大文件不再撞以前的 64MB 上限，上传过程有进度、可取消，切换会话后上传状态仍然可见。

### 4. 新增右侧栏与文件预览

会话右侧新增侧栏，支持多标签、分栏与全屏，可直接预览 Markdown、代码、HTML、PDF 与图片，包括子代理以及当前未打开会话里的文件。模型也可以显式交付文件，供你在侧栏预览、用默认应用打开或在文件管理器中定位。原来的 Detail 面板已移除。

### 5. 另外几件值得知道的事

- 如果你用 Clash 之类的系统代理，应用自身的网络请求与插件安装现在会遵循环境里的 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY` 设置；访问本机自身地址的流量永远不走代理。
- MCP 服务返回重复的工具列表分页时，不再把启动卡住。
- Windows 上 dsh 自己的后台子进程不再闪控制台窗口。
- 手机界面保持原有的 项目 / 信息 标签。会话日志导出入口改成了会话头部的一个"更多"菜单，在手机上照旧隐藏。
