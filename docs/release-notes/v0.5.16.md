This release ships a new bundled harness runtime (0.1.5-rc.2 to 0.1.6-alpha.1) and brings the upstream feature wave to desktop and phones: a terminal in the web sidebar, sidebar previews for file references, a reorganized composer plus menu, and an upgraded MCP stack. The desktop shell itself needed zero code changes: every patch and contract check held as-is, and the mobile adaptation layer was re-verified in a real browser at phone width. Session data and configuration are unaffected; a normal in-place update is enough.

### 1. What is new in the harness runtime

- Terminal in the web sidebar: multiple tabs, shell selection, and recovery after page refreshes. On Windows the shells run through ConPTY, so nothing flashes a console window on your desktop.
- File, skill references and delivered-file links now open in the sidebar preview by default, alongside the workspace file browser.
- The composer plus menu was reorganized: adding files moved into the menu and the standalone attachment button is gone. On phones the shell's own image-attachment button comes back automatically next to the plus button (see section 3).
- MCP integration upgraded to the official SDK v2: protocol negotiation, paginated tool lists, servers without tools, plus resource discovery and URI templates. An optional plugin failing at startup no longer affects the other plugins; only a required plugin failure exits.
- Experimental additions: Browser Use, Computer Use, and Auto review mode. Headless mode can read tasks from standard input, resume a session by id, and emit JSON run events.
- DeepSeek requests now default to the Messages protocol. If you manually configured the old official API root, remove that override or change it to https://api.deepseek.com/anthropic.

### 2. Mobile checks re-run at phone width

The mobile adaptation layer was verified against the new runtime in a real browser at 390 px: no horizontal overflow, the composer stats row and the iconified model trigger behave as before, the session header stays clean, and the layout holds across the 500/700/720 px breakpoints. The new sidebar terminal is usable at phone width (a test command ran end to end), and the new sidebar file preview opens and collapses without trapping the page.

### 3. Compatibility

Session format is unchanged (still V3), so the one-way upgrade rule from 0.1.5 does not change. Your DSH home (sessions, MCP servers, skills, open-with choice) survives install, uninstall and reinstall as before. One visible upstream change on phones: the standalone attach button in the composer was removed upstream, and the shell's image-attachment button automatically takes its old place next to the plus button, while the plus menu's file entry also works.
