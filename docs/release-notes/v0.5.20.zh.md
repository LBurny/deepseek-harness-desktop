# 中文说明

[← 返回 v0.5.20 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.20) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.20)

本版集中修三件反馈：深色模式启动后 UI 不跟随（0.5.19 引入的壳侧回归，已根治）、手机端上下文用量圆环挪进「信息」页、内置 /init 插件补上双语说明。运行时版本不变（仍是 0.2.0-rc.1），会话格式不变（V4），按正常覆盖安装升级即可。

### 1. 深色模式启动后 UI 不跟随（根治）

0.5.19 起 dsh 0.2.0 把设置文件 `settings.yaml` 废除为一次性迁移通道（每次启动导入进新存储后改名），而壳仍在每次启动重建它——导入的旧值每次都把你在应用里选的主题覆盖回去，表现为"深色模式启动后 UI 是浅色，重启服务反而正常"。本版壳全面改用 dsh 0.2.0 的新设置存储（profile 补丁文件里的设置条目）：标题栏主题与壳语言实时跟随你在应用里的选择，不再有每次启动被旧值覆盖的回路；顺带退役了首启主题播种（0.2.0 起双端缺省都是"跟随系统"，首启即一致）。升级后无需任何操作，选过的主题/语言原样保留。

### 2. 手机端：上下文用量圆环搬进「信息」页

0.2.0 在输入框下方新增的上下文用量圆环（"○ 26%"）在手机上单独占一行很突兀。现与回合统计行同款处理：挪进顶部「信息」页、放在统计明细上方，输入框下方不再单独显示。它只在有用量数据时出现，信息页里的展示随数据实时更新；与统计行一样是不可点读数（明细面板仍在桌面端点圆环查看）。

### 3. /init 插件有了双语说明

插件管理页里我们的 /init 插件此前是唯一没有描述的。现按上游插件元信息机制补了中英文案：中文界面显示「初始化命令——创建或更新当前工作区的 AGENTS.md 指令文件…」，英文界面显示对应英文，随界面语言切换即时跟随。已装用户升级后自动获得，无需重装或重新启用。

### 4. 兼容性

运行时与会话格式都不变，你的主题/语言选择、会话、MCP 配置、技能全部原样保留，覆盖安装即可。0.5.19 时代被改名残留的 `settings.yaml.imported` 无害，壳不再读写它。Rust 全量测试通过（290 条，0 失败），含对真实运行时逐项探测的契约套件（新增五条设置存储探针）。
