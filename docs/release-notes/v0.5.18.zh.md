# 中文说明

[← 返回 v0.5.18 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.18) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.18)

本版修好手机端会话头部：会话名被挤到看不见，模式、后台任务、打开方式几个控件叠在一起。根因在上游布局而非壳——头部完全没做窄屏适配。其余一切不变：按正常覆盖安装升级即可，会话、MCP 配置、技能与各项选择都原样保留。手机上刷新一次页面即可拿到修复。

### 1. 问题出在哪

在真实窄视口上量过（390px，临时 dsh 实例 + Playwright 驱动的浏览器）：头部行把标题挤到 **0 像素宽**，会话名在页面里完全不可见，只有手机浏览器自己的标题栏里还剩一份。原因是三个尾部组里有两个声明了 `flex: none`、永不退让，而标题所在的面包屑是 `min-width: 0`、第一个被牺牲。同一行里再放上"模式"药丸（68px）和"N 个后台任务"药丸（101px，会话有后台任务时才渲染），动作组的内容长到 177px 塞进一个装不下它的盒子里，药丸最终**压住右侧按钮 9px**——就是那张"挤在了一起"的实拍。

### 2. 修法

移动端样式表只动弹性、不藏任何控件。标题、模式、后台任务三者各拿一个 `min(px, vw)` 下限且允许收缩，谁都不会被挤没；很窄的机型上下限随视口退让，320px 也不重叠。"模式"药丸多一步：它的文案是药丸里的匿名弹性项，药丸自身的 `text-overflow` 对匿名项不起作用（原生 `max-width: 180px` 只是硬裁），改成 `inline-block` 后省略号才真正渲染，图标也显式转回行内，22px 的药丸不会变成两行高。后台任务与计划药丸（两者共用同一套类名）的计数补上省略号、宽度跟住容器，于是"4 个后台任务"变成"4 …"，不再把标题顶出去。最后头部自身的左右内边距从 20/28 收到 12/12，右上角按钮的负外边距同步补偿——白得 24px 给标题，而右上开关仍距屏缘 12px。

### 3. 验证

量了九档宽度（320、360、375、390、414、500、600、700、720）：每一档行内间隙恒为 12px、行永不溢出、头部恒高 76px。600px 及以上三件恢复原生完整形态，701px 及以上所有规则都不生效，桌面壳与宽屏远程和改动前逐像素一致。Rust 全量测试通过（306 条，0 失败），含新增的规则级回归测试与六条针对头部锚点的契约探针。

### 4. 兼容性

运行时版本不变、会话格式不变、配置不变。覆盖安装即可。
