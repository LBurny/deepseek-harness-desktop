# 中文说明

[← 返回 v0.5.23 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.23) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.23)

本版两项修复：桌面端网页搜索结果等外链点击恢复可用（此前被静默吞掉）；手机端会话头部改为「标题钉住 + 药丸可滑动条」，任务运行场景不再挤乱。运行时与会话格式不变，覆盖安装即可。

### 1. 桌面端：网页搜索结果等外链点了"没反应"

在 dsh 消息流里点外链（网页搜索结果等）毫无反应：浏览器不弹、壳内无窗、页面无报错。根因在壳不在 dsh：dsh 打开外链的终点是 `window.open`，WebView2 对它发 `NewWindowRequested` 事件，而壳主窗口没挂处理器时，WebView 层的兜底是标记"已处理"并**静默吞掉**。现在主窗口自己处理该事件：http/https 链接交给系统浏览器打开、壳内永不弹新的 WebView2 子窗，非 web 协议（javascript:/data:/file:/自定义协议）一律拒绝。

### 2. 手机端：会话头部改「标题钉住 + 药丸滑动条」

任务运行场景下 390px 的会话头部彻底挤乱："2 个子智能体"药丸的计数被压成逐字竖排六行（头部高度 76→160px），"N 个后台任务"药丸整个被顶出屏外。根因全在上游：子智能体药丸的计数 label 引用了一个其 CSS module 里根本不存在的 `.count` 类（死引用），退化为零约束的裸文本，一受挤压 CJK 就逐字断行；后台任务药丸的根节点则完全不可收缩。

此前"逐个药丸调最小宽度"的硬编码路线跟不上上游持续加药丸的节奏，本版把药丸区整体改成**横向可滑动条**——与设置弹窗的导航条同款交互：药丸保持天然宽度、永不被压缩（竖排/折行/重叠在机制上不可能发生），放不下的部分由滑动条收纳，上游将来新增药丸自动进条、壳零适配。会话标题钉在条外、保留最小宽度，恒可见、超宽省略号。滚动条做了隐藏（顺带消掉桌面 Chromium 经典滚动条把头部撑高 3px 的伪影），横向滑到尽头不会串到页面级手势。已按真实 dsh 0.2.0-rc.1 实例在 320~720px 九档宽度实测：始终单行、条可滑到底、标题恒可见、头部高度恒定；720px 以上与上游原生逐字节一致。

### 3. 兼容性

运行时与会话格式不变，会话、MCP 配置、技能、主题与语言选择全部原样保留。Rust 全量测试通过（292 条，0 失败），含改钉滑动条机制的头部锚定测试与外链协议门回归。
