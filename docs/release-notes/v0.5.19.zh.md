# 中文说明

[← 返回 v0.5.19 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.19) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.19)

本版内嵌运行时从 0.1.6-alpha.1 升到 0.2.0-rc.1，一次跨过上游 6 个版本：插件管理页、定时任务与提醒、会话归档、快捷键自定义、文件改动审阅等纷纷到位。壳侧随动：退役两个已被上游原生接管的运行时补丁（资源管理器窗口显示、陈旧锁自愈），手机端两处适配小修。**会话格式升级到 V4（单向）**，其余一切照旧：数据目录、配置、技能、MCP 全部原样保留，按正常覆盖安装升级即可。

### 1. 升级前须知：会话格式 V4，不可降级读取

上游把会话日志格式从 V3 升到 V4，并自带迁移。升级后首次启动时旧会话自动迁到新格式（原文件保留），此后新产生的会话都是 V4——**旧版本读不了 V4 会话**。也就是说：升级后如果想退回 0.5.18 或更早的版本，升级前已有的会话仍能打开（V3 原件还在盘上），升级之后产生的会话打不开。会话迁移在真机验收中已覆盖"保留数据目录升级首启"场景。升级本身无需任何操作。

### 2. 运行时新东西（跨 0.1.6~0.2.0 三条线的精选）

- 插件管理页：安装、配置、启停、运行时卸载；安装可选官方源、国内镜像或自定义源，首次安装自动选可访问的源。
- 定时任务与提醒：创建和管理提醒、查看运行记录、重启后保留，最短每分钟重复一次。
- 会话归档：置顶、筛选、恢复；归档运行中的会话会先确认受影响的任务。
- 快捷键：查看、搜索、自定义、恢复，侧边栏同步显示当前键位。
- 文件改动审阅：回合结束出改动卡片，侧栏逐文件对比（左右分栏、代码高亮、同步滚动）。
- 侧栏预览扩展：Word、Excel、PowerPoint、CSV、TSV；Excel 支持工作表切换、单元格选择与公式。
- 自动审阅（实验性）：可启用，拒绝操作后可由你决定是否继续。
- 全新安装首次启动自动创建默认工作区和空白会话，不用先选文件夹；另有首次使用引导（介绍额度与用途选择，升级后可能出现一次）。
- DeepSeek 账号模型的会话无需配置 API Key 即可网页搜索；账号任务与 API Key 任务使用独立模型入口。
- Windows 内置沙箱新增权限诊断技能；工具调度异常后对话可以继续，不再整体卡死。
- 更多：语音输入（实验性）、MCP 资源发现与 URI 模板、SSH 远端工作区（实验性）、浏览器模式/子代理会话/提交计划的侧栏面板、关闭窗口后任务继续在后台跑（退出前会提示影响）。

### 3. 壳侧变化

- **资源管理器补丁退役**：0.5.17 修的「在文件资源管理器中显示/打开所在文件夹点了没反应」上游已在 0.2.0 原生修复（原生命令 runner 参数化，explorer.exe 显式以可见方式拉起），壳的旧补丁按预案移除——行为不变，窗口照常弹出并选中文件。
- **陈旧锁自愈退役**：0.5.13 修的"硬杀一次可能永久起不来"（死锁卡启动）由上游根治——dsh 0.2.0 的写锁自带孤儿接管（持有者进程已死即自动清理并重试），壳不再每次启动前预扫。
- **手机端两处适配**：输入框改为 contenteditable 富文本后，16px 字号规则补齐选择器（iOS 聚焦防自动缩放的双保险恢复有效）；侧栏抽屉的宽度与阴影适配新的槽位包装结构。顺带清理了一条指向已消失控件的失效规则。
- 内测声明豁免播种跟随上游新命名空间（ui-settings-general）；旧设置文件里的 ui-onboarding 段无害保留。
- 手机端已按 390px 真实视口复验：会话头部防挤压（0.5.18 的修复继续有效）、统计行搬移、模型触发器图标化、设置弹窗全屏化全部通过；720px 以上回到原生形态。

### 4. 兼容性

会话格式 V3→V4 单向（见第 1 节）是本版唯一的兼容性断点。DSH 数据目录（会话、MCP 配置、技能、各项选择）在安装、卸载、重装时照旧全部保留；覆盖安装即可，手机端刷新一次页面即可拿到新适配。Rust 全量测试通过（290 条，0 失败），含对真实运行时逐项探测的契约套件。
