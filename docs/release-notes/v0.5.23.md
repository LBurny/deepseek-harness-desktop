This release has two fixes: web search results and other external links on the desktop now actually open in your browser (they were silently swallowed before), and the session header on phones gets a swipeable pill strip instead of breaking when pills multiply during a running task. No runtime or session format change; update in place.

### 1. Desktop: external links (web search results, etc.) open again

Clicking an external link in dsh's message stream did nothing: no browser, no window, no error. The cause was in the shell, not dsh: dsh opens external links via `window.open`, which WebView2 turns into a `NewWindowRequested` event — and with no handler attached, the WebView layer's fallback is to mark the request handled and silently drop it. The main window now handles the event itself: http/https links are handed to your system browser, no new WebView2 window is ever created inside the shell, and non-web schemes (javascript:, data:, file:, custom protocols) are refused outright.

### 2. Mobile: session header becomes "pinned title + swipeable pill strip"

With a task running, the 390px session header broke badly: the "2 subagents" pill's count stacked vertically character by character (header height ballooned from 76px to 160px) and the background-jobs pill was pushed off screen entirely. The root causes are all upstream: the subagent pill's count label references a `.count` class that does not exist in its CSS module (a dead reference), leaving it an unconstrained bare span that wraps CJK text per character under pressure, and the jobs pill's root cannot shrink at all.

The previous approach — tuning a minimum width per pill — could not keep up as upstream keeps adding pills, so the header pills area is now a horizontally swipeable strip, the same pattern as the settings dialog's navigation row: pills keep their natural width and can never be squeezed (vertical stacking, wrapping and overlap become mechanically impossible), overflow is collected by the strip, and any pill upstream adds in the future joins the strip with zero shell-side adaptation. The session title stays pinned outside the strip with a guaranteed minimum width, always visible with ellipsis. Scrollbars are hidden (which also removes a 3px header-height artifact caused by classic scrollbars on desktop Chromium), and horizontal overscroll is contained so a hard swipe can't bubble into page-level gestures. Verified on a real dsh 0.2.0-rc.1 instance at nine widths from 320px to 720px: single row, strip scrolls to the end, title always visible, constant header height; at 720px and above the header is byte-for-byte upstream native.

### 3. Compatibility

No runtime or session format change. Sessions, MCP servers, skills and theme/language choices are all preserved. The full Rust suite passes (292 tests, 0 failures), including the reworked header-mechanism anchors and the external-link scheme gate.
