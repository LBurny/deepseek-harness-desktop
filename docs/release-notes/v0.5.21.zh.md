# 中文说明

[← 返回 v0.5.21 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.21) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.21)

dsh 0.2.0 起自带了完整的插件管理页（安装、配置、启停、运行时卸载，支持官方源/国内镜像/自定义源），壳自己的插件管理面板成了重复维护面。本版按你的裁定把它整体退役：托盘不再有"插件管理"项，壳内页面与配套命令一并移除。装/卸插件请直接用 dsh Web UI 里的插件页。运行时与会话格式不变，覆盖安装即可。

### 1. 变了什么

- 托盘菜单不再有"插件管理"；壳内不再有插件面板页面、窗口与配套后台命令。
- 在 dsh 的插件页里能看到同样的内容且更全：官方可选插件、已装插件（含我们的 /init，现带双语说明）、安装源选择、运行时启停与卸载。
- 内置 /init 插件的播种与守护逻辑不变：升级自动同步新文件；你在 dsh 插件页里卸载它之后不会被壳复活（"用户已删不复活"语义不变）。

### 2. 没变什么

技能管理、MCP 管理、远程访问、诊断、设置等其它托盘项原样保留；会话、MCP 配置、技能、主题与语言选择全部原样。MCP 管理暂不在本次退役范围（其壳侧编辑的是 dsh 面板之外的底层补丁文件，后续视 dsh 面板覆盖度另行评估）。Rust 全量测试通过（283 条，0 失败），前端构建通过。
