# 中文说明

[← 返回 v0.5.16 发布页](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.16) | [English](https://github.com/LBurny/deepseek-harness-desktop-releases/releases/tag/v0.5.16)

本版内嵌运行时从 0.1.5-rc.2 升到 0.1.6-alpha.1，把上游这轮功能带给桌面与手机：Web 侧边栏终端、文件引用侧栏预览、加号菜单重组、MCP 升级官方 SDK v2 等。壳本身零代码改动：全部补丁与契约检查原样通过，手机适配层在真实浏览器按手机宽度复验。会话数据与配置不受影响，按正常覆盖安装升级即可。

### 1. 运行时新东西

- Web 侧边栏新增终端：多标签、Shell 选择、刷新后恢复。Windows 上 shell 走 ConPTY，不会在桌面弹出控制台窗口。
- 文件、Skill 引用及交付文件链接默认改为侧边栏预览，与原有工作区文件浏览并列。
- 输入框加号菜单重组：文件添加入口移入菜单，独立附件按钮移除。手机端壳自带的「添加图片附件」按钮会自动回到加号旁边（见第 3 节）。
- MCP 升级官方 SDK v2：协议协商、工具列表分页、支持无工具服务器，并新增资源发现与 URI 模板。可选插件启动失败不再影响其他可用插件，只有必需插件失败才会退出。
- 新增实验性功能：Browser Use、Computer Use、Auto review 模式。Headless 支持从标准输入读任务、按 id 续会话、`--json` 逐行输出运行事件。
- DeepSeek 请求默认改用 Messages 协议。如果你手动配置过旧官方 API 根地址，请移除该配置或改为 `https://api.deepseek.com/anthropic`。

### 2. 手机端检查按手机宽度重跑

手机适配层已在真实浏览器按 390px 宽度对新运行时复验：无横向溢出，统计行与图标化的模型触发器和之前一致，会话头部保持干净，500/700/720px 断点下布局同样稳定。新的侧边栏终端在手机宽度可用（测试命令完整跑通），新的侧栏文件预览开合顺畅、不会困住页面。

### 3. 兼容性

会话格式不变（仍是 V3），0.1.5 的「升级后不可降级读取」口径不变。你的 DSH 数据目录（会话、MCP 配置、技能、打开方式选择）在安装、卸载、重装时照旧保留。手机端一处可感的上游变化：输入框的独立附件按钮被上游移除，壳的「添加图片附件」按钮自动补回原位，加号菜单里的文件入口同样可用。
