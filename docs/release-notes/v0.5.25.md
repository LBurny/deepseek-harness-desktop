This release fixes the preinstalled `/init` command failing its whole turn under dsh's session format V4, and reorganizes the Rust backend internally with zero behavior change. No runtime or session format change; update in place.

### 1. Fixed: /init failed with "format v4 message requires a producer-owned source kind"

dsh 0.2.0's session format V4 retired the generic `kind: "plugin"` message-source wrapper: durable messages must now declare a producer-owned source kind, and anything still writing the retired syntax fails its whole turn. The preinstalled `/init` plugin (built in the 0.1.2 era) still submitted its AGENTS.md authoring prompt under the retired wrapper, so every invocation died instantly with the error above. The plugin now emits `kind: "command-init"` with `form: "notice"` — the same shape upstream's own plugins use (plan-mode writes `kind: "plan-mode"`, tool-goal writes `kind: "tool-goal"`); the collapsed context-injection row renders exactly as before, keyed on the notice form. Historical messages in old sessions are safe: the V3→V4 migrator rewrites legacy plugin wrappers automatically (unregistered names fall back to `plugin:<name>` attributions).

### 2. Internal reorganization

Six independent commits, each with the full Rust suite green. `dsh/` now holds the process supervisor, credentials, upstream facts, presets, port and runtime modules (upstream.rs remains the single file to touch when following new dsh releases). `bootstrap/` gathers startup self-healing behind one entry point (`run_all`: patches → pnpm store heal → plugin preseed), with all startup patches collected under `bootstrap/patches/` — adding or retiring a patch now edits a single file. `ui/` holds shell window facilities, with a new `state.rs` that removes the theme↔tray circular reference. `features/` holds the local-pages backends (commands.rs merged into diagnostics.rs). Four new top-level files: logging.rs (unified events.log append layer), redact.rs (token redaction), patchstore.rs (generic cordis.patch.yml entry store, split out of mcp.rs), and eventbridge.rs (process-to-window event bridge). lib.rs shrank from 1061 to 482 lines and now contains only builder assembly.

### 3. Compatibility

Nothing user-visible changed beyond the /init fix: the 293-test suite passes (3 ignored, 0 failures), Tauri command names are untouched (the three-way command registration anchor tests pass unmodified), installer hooks, capabilities and the update flow are identical, and settings, sessions, MCP servers, skills and theme/language choices are all preserved.
