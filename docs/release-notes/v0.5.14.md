This release keeps your interface preferences alive across restarts and evens out the input bar on phones. The bundled DeepSeek Harness runtime is unchanged, and no session data is affected - a normal in-place update is enough.

### 1. Fixed: "Open with" and other preferences reset on every restart

Your choice in the session header (VS Code vs File Explorer) went back to the default after every restart, and a few other interface preferences (conversation width, current session, trajectory duration) forgot themselves too. The cause: these preferences live in browser storage, which is keyed by the exact local address including the port, and the app picked a fresh random port on every launch - so every start looked like a brand new site with no memory. The app now remembers the port it used and reuses it on the next start, so preferences stick. Note: please pick your preferred app once more after this update; the old choice was stored under an abandoned random address and cannot be carried over.

### 2. Fixed: unevenly spaced input bar on phones

On the phone UI, the bottom toolbar of the input box (the "+" and attachment buttons on the left, the model picker, usage ring and send button on the right) had visibly uneven gaps. The toolbar now uses one button size and one spacing throughout, and the two small drop-down arrows are gone, leaving a clean icon-only row in line with common mobile practice. All menus open exactly as before.
