This release upgrades the bundled DeepSeek Harness runtime to the 0.1.5 line and adapts the shell to it. Most of the upgrade is invisible, but three things are worth reading before you update.

### 1. Read this first: sessions upgrade in one direction

The new runtime stores sessions in a new format. When you open an older session it is converted, and the original file is kept, but a converted session can no longer be read by the older runtime. If you later go back to an earlier version of the app, those sessions will not open. There is no way around this, and it comes from dsh itself rather than from the shell.

### 2. Read this if you use Minimal mode

In Minimal mode the model now gets a persistent shell only. The file reading and editing tools that this mode used to include are no longer part of it. This is an upstream change. The other modes are unchanged.

### 3. Uploading from your phone now works for any file type

dsh accepts any kind of file now, and the remote link streams uploads through instead of collecting them in memory first. Large files sent from your phone no longer fail at the old 64 MB limit. Uploads show progress, can be cancelled, and stay visible if you switch sessions.

### 4. New right sidebar with previews

Sessions now have a right sidebar with tabs, a split view and fullscreen. It previews Markdown, code, HTML, PDF and images, including files from subagents and from sessions you are not currently in. Models can also hand you a file for preview, opening it in its default app, or revealing it in the file manager. The old Detail panel is gone.

### 5. Smaller things worth knowing

- If you use a system proxy such as Clash, the app's own network requests and plugin installs now follow the `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` and `NO_PROXY` settings from the environment. Traffic to your own machine never goes through the proxy.
- An MCP server that returns a repeated tool-list page no longer stalls startup.
- On Windows, dsh's own background processes no longer flash console windows.
- The phone interface keeps its 项目 / 信息 tabs. The session log export moved into a "more" menu in the session header, and stays hidden on the phone as before.
